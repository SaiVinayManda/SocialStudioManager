# Official platform boundaries (disabled)

All current publishing is local mock operation. `official-plans.mjs` builds credential-free plans only; `executeOfficialPlan` fails closed. There is no connected OAuth client, upload transport, public media host or live publishing switch. The internal Docker network deliberately provides no live API egress. A future live deployment requires distinct account, network and exact-post approvals; it cannot be enabled by editing one flag.

YouTube accepts video media uploads; the local QC profile is MP4 H.264/AAC, 1080x1920, roughly 60 seconds. Instagram's official collection specifies MOV/MP4, H.264/HEVC, AAC 48 kHz, 23–60 fps and recommends 9:16. Platform-specific frame rate/audio/size/duration limits must be applied with a pinned API contract before live delivery; the current general FFprobe profile alone does not certify all platform constraints. No quota or account limit is assumed fixed.

There are no saved tokens in workflow JSON, job rows or request plans. Social-account records hold future credential references only. Token refresh, reconnect, permission loss, upload-session persistence, Retry-After interpretation, platform status polling and exact API reconciliation need credentialed contract/integration tests after separate approval. An upload timeout with no definitive receipt must stay outcome_unknown/manual_review. Do not rerun a public upload merely because n8n reports a retryable execution error.
